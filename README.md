
🇮🇳 Bharat Sahayak AI

AI-Powered Government Scheme Discovery and Assistance Platform

📌 About the Project

Bharat Sahayak AI is an AI-powered platform designed to help Indian citizens discover government welfare schemes easily through Telugu and English language support.

It helps users understand scheme benefits, eligibility criteria, required documents, and application procedures in simple language.

🚨 Problem Statement

Many people are unaware of government schemes and struggle to find accurate information about eligibility, benefits, required documents, and application procedures due to language barriers and lack of awareness.

💡 Proposed Solution

Bharat Sahayak AI provides a simple platform where users can discover suitable government schemes based on their needs and receive guidance in Telugu and English.

⭐ Key Features

- Government Scheme Discovery
- Telugu and English Language Support
- AI-Based Assistance (planned integration)
- Basic Eligibility Checking
- Required Documents Information
- Step-by-Step Application Guidance
- Official Government Website Links

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- JSON
- AI/NLP (planned integration)

🎯 Objectives

1. Increase awareness of government welfare schemes.
2. Reduce language barriers.
3. Make scheme information easy to understand.
4. Help citizens identify potentially suitable schemes.
5. Improve digital accessibility.
