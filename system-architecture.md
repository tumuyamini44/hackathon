System Architecture – Bharat Sahayak AI

Architecture Overview

The Bharat Sahayak AI platform follows a simple client-server architecture.

System Flow

Citizen / User
↓
Frontend Interface
↓
Flask Backend API
↓
Scheme Search Module
↓
Government Scheme Database (JSON)
↓
Scheme Information and Official Links

Main Components

1. Frontend

- HTML
- CSS
- JavaScript
- User-friendly interface
- Telugu and English interface labels

2. Backend

- Python
- Flask Framework
- API handling
- Scheme search and filtering

3. Database

- JSON-based sample scheme dataset
- Scheme names
- Categories
- Benefits
- Documents
- Official website links

4. Eligibility Module

- Collects basic user information.
- Applies simplified demonstration rules.
- Displays preliminary guidance.

Future AI Integration

- Natural Language Processing (NLP)
- AI chatbot
- Voice-based assistance
- Personalized scheme recommendations
- Regional language support

Conclusion

The architecture provides a foundation for developing an accessible government scheme discovery platform.
